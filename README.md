
# South African Economic Dashboard 🇿🇦

## Overview

A beginner-friendly Python project exploring South Africa's economy through publicly available economic data.

## Objectives

- Track South African inflation (CPI).
- Explore interest rate movements.
- Monitor the rand against the US dollar.
- Examine GDP growth.
- Identify economic trends through data visualisation.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter / Google Colab

## Project Status

🚧 Initial setup — data collection and analysis to follow.

## Purpose

To develop practical skills in Python, economic research, financial analysis and data visualisation.
